## 2. 已确认的技术结论（2026-08-16）

1. **四元数顺序 = wxyz（scalar-first）**。`build_srth_dataset.py` 读入后重排为 xyzw 再交给 scipy，脚本内置单元自检（6/6 PASS）。注意 scipy 1.17 已移除 `Rotation.slerp`，自检使用自带实现。
2. **双坐标系位姿**：PLC 同时输出机械臂基坐标系与镜坐标系两套**位置**。动作标签 `delta_pos` 用镜系（与 arm_2 相机锚点同系、内窥镜移动时自动含自我运动补偿）；基座系位姿存入元数据。
3. **PLC 无镜系四元数（已上报的遗留风险）**：`delta_rot_6d` 暂用基座系四元数计算，相对旋转角度不变但旋转轴差一个「基座系->镜系」的未标定旋转。短期可接受（内窥镜固定时误差恒定），长期需要标定该固定变换或让 PLC 侧补充镜系姿态输出。
4. **gripper_angle**：全局量程约 [-55, +85]（arm_1 [-43.1, 83.6]、arm_3 [-54.4, 50.3]），各臂静止值按器械聚类；`gripper_signal` 恒 0，张开方向离线不可证，暂约定「角度增大 = 张开」，待 T5/T6 实测确认。归一化占位：`jaw = clip((ga + 60) / 150, 0, 1)`。
5. **30 Hz 方案不变**：arm_2 内窥镜锚点 + `target_fps` 软件网格抽帧；腕部相机 15 ms 阈值过滤；四臂位姿 LERP/SLERP 插值（误差 < 1 ms）。

## 1. 背景与问题

### 1.1 现状

PLC 同时输出两套末端**位置**：

- `EndEffector_Coordinate_ArmFrame[4][3]`（机械臂基坐标系）
- `EndEffector_Coordinate_ScopeFrame[4][3]`（镜坐标系）

但**姿态四元数只有一套**：`EndEffector_Orientation[4][4]`（wxyz）。

`build_srth_dataset.py` 的动作标签：

- `delta_pos`：用 **ScopeFrame（镜系）位置**差分（与 arm_2 内窥镜相机锚点同系，内窥镜移动时自动含自我运动补偿）✅
- `delta_rot_6d`：目前用 **`EndEffector_Orientation`（基座系？）四元数**计算相对旋转

### 1.2 遗留风险

> 若 `EndEffector_Orientation` 定义在**基座系**，则 `delta_rot_6d` 的旋转轴与镜系动作轴相差一个「基座系 → 镜系」的**未标定常值旋转**：小角度下旋转角不变、旋转轴错误。内窥镜固定时该误差为常值，短期可接受，但正式训练前必须确认或标定。

## 3. 若需要标定固定变换（Q2 = 不建议改 PLC）

### 3.1 方案：并入 T7 手眼标定环节

对**每条臂**估计常值旋转 `R_arm`，满足：

```
q_scope = R_arm ⊗ q_base   （或 q_base = R_arm ⊗ q_scope，以 Q1 答案为准）
```

### 3.2 所需材料（操作者/现场准备）

| 材料 | 用途 |
|---|---|
| 标定板（棋盘格 9×6，与 T7 内参标定共用） | 相机标定板 |
| 机器人臂端标记物（如探针尖端+标定板配合） | 建立臂端↔视觉对应 |
| 至少 8–10 组不同位姿（臂动+内窥镜固定） | 求解固定旋转 |
| 内窥镜（arm_2 相机）正常工作 | 视觉观测 |

### 3.3 标定步骤概要（确认后细化）

1. 内参标定完成（T7 输出 `intrinsics.yaml`）。
2. 内窥镜固定，臂端标记物在视野内摆出 ≥8 组位姿，同时记录：PLC 四元数（基座系）、PLC 镜系位置、内窥镜中标定板/标记物位姿。
3. 解 PnP + 最小二乘求常值旋转，验证残差。
4. 将 `R_arm` 写入标定文件（`calibrations/<id>/hand_eye/`），`build_srth_dataset.py` 读取并应用。
